# Attribution and capacity

## Capacity

This SDK is developed and published independently, in a personal
capacity, by its author — Kevin Ferguson. **It is not
developed on behalf of, endorsed by, or representative of Durham County
Council or any other employer.** Any views, design decisions, or errors
in this project are the author's own.

This project has been submitted to the UK Strategic Data Roadmap
(OCDO/GDS), under the Data Architecture category, with Data Governance
flagged as the most useful support area — given the licensing
uncertainty documented across several European feeds (see
[`docs/governance/licensing.md`](licensing.md)'s "European-feed
licensing uncertainty is a real, recurring pattern" note). That
submission is a further reason the capacity statement above needs to be
explicit and easy to find, rather than left implicit.
